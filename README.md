# Arithmetic-logic-unit
This project is an 8-bit Arithmetic Logic Unit (ALU) simulator implemented in C++. It performs various bitwise and arithmetic operations, including:

Basic logic gates (NAND, NOT, OR, AND, XOR, NOR)
1-bit and full adders for binary addition
Multiplication using bit shifting and addition
Shifting operations (left/right)
Comparison of two 8-bit numbers
Binary decoder for operation selection
The ALU takes two 8-bit binary inputs and executes the desired operation based on a 3-bit control signal. This project demonstrates fundamental digital logic and arithmetic operations using bitwise manipulation.
